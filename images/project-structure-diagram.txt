│                            🛠️ Development Commands                            │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  🚀 Quick Start:                                                                │
│  ├── make local    → Start with local PostgreSQL + sample data                │
│  ├── make run      → Start with remote Supabase database                      │
│  ├── make status   → Check container health status                            │
│  ├── make logs     → View application logs                                    │
│  └── make clean    → Stop and cleanup containers                              │
│                                                                                 │
│  🔧 Manual Development:                                                        │
│  ├── Backend: python manage.py runserver                                      │
│  └── Frontend: npm run dev                                                     │
